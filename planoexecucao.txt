IDEIA DO BANCO:

TABELA: USUARIOS

- id
- nome
- email
- senha
- telefone
- cidade
- estado
- foto
- data_cadastro

Relacionamentos:
- Um usuário pode cadastrar vários serviços.
- Um usuário pode fazer várias solicitações de orçamento.
- Um usuário pode receber várias solicitações por meio dos serviços que oferece.
- Um usuário pode fazer várias avaliações.
- Um usuário pode receber várias avaliações.


TABELA: CATEGORIAS

- id
- nome
- descricao

Relacionamentos:
- Uma categoria pode possuir vários serviços.
- Cada serviço pertence a uma categoria.


TABELA: SERVICOS

- id
- usuario_id
- categoria_id
- titulo
- descricao
- ativo
- data_cadastro

Relacionamentos:
- Cada serviço pertence a um usuário.
- Cada serviço pertence a uma categoria.
- Um usuário pode cadastrar vários serviços.
- Um serviço pode receber várias solicitações de orçamento.


TABELA: SOLICITACOES

- id
- cliente_id
- servico_id
- mensagem
- status
- data_solicitacao

Relacionamentos:
- Cada solicitação é feita por um usuário.
- Cada solicitação pertence a um serviço.
- O dono do serviço é o usuário que está recebendo a solicitação.
- Um usuário pode fazer várias solicitações.
- Um serviço pode receber várias solicitações.
- Uma solicitação concluída pode gerar uma avaliação.


TABELA: AVALIACOES

- id
- avaliador_id
- avaliado_id
- solicitacao_id
- nota
- comentario
- data_avaliacao

Relacionamentos:
- Cada avaliação é feita por um usuário.
- Cada avaliação é destinada a outro usuário.
- Cada avaliação está ligada a uma solicitação.
- Um usuário pode fazer várias avaliações.
- Um usuário pode receber várias avaliações.
- Uma solicitação pode ter no máximo uma avaliação.


USUARIOS 1 ---- N SERVICOS

CATEGORIAS 1 ---- N SERVICOS

USUARIOS 1 ---- N SOLICITACOES
(cliente que solicitou)

SERVICOS 1 ---- N SOLICITACOES

USUARIOS 1 ---- N AVALIACOES
(avaliador)

USUARIOS 1 ---- N AVALIACOES
(avaliado)

SOLICITACOES 1 ---- 0..1 AVALIACOES

CHAVES estrangeiras:
SERVICOS.usuario_id
→ USUARIOS.id

SERVICOS.categoria_id
→ CATEGORIAS.id

SOLICITACOES.cliente_id
→ USUARIOS.id

SOLICITACOES.servico_id
→ SERVICOS.id

AVALIACOES.avaliador_id
→ USUARIOS.id

AVALIACOES.avaliado_id
→ USUARIOS.id

AVALIACOES.solicitacao_id
→ SOLICITACOES.id
